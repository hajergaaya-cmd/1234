## 🚀 البدء السريع

### للطالبات:

1. افتحي الموقع: `https://username.github.io/project-name`
2. اختاري النشاط المطلوب
3. ابدئي التفاعل!

### للمعلمات:

#### الطريقة 1: استخدام GitHub Pages (موصى به)

1. أنشئي حساب على [GitHub.com](https://github.com)
2. أنشئي repository جديد
3. ارفعي جميع الملفات
4. فعّلي GitHub Pages من Settings → Pages
5. شاركي الرابط مع الطالبات!

#### الطريقة 2: التحميل المباشر

1. حمّلي المشروع كملف ZIP
2. فكّي الضغط
3. افتحي `index.html` في المتصفح
4. شاركي الملفات مع الطالبات عبر Google Drive / OneDrive
