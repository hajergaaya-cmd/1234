دليل رفع المشروع على GitHub

خطوة بخطوة - سهل وواضح

1
إنشاء حساب GitHub
  1. اذهبي إلى github.com
  2. اضغطي على Sign up
  3. أدخلي البريد الإلكتروني: hajergaaya@gmail.com
  4. اختاري كلمة مرور قوية
  5. اختاري اسم مستخدم (username) - سيظهر في رابط موقعك
  6. أكملي التحقق وفعّلي الحساب من البريد

💡 نصيحة

اختاري username احترافي مثل: hajergaaya أو teacher-activities
سيصبح رابط موقعك: https://username.github.io/project-name

2
إنشاء Repository جديد

Repository = مستودع = مجلد المشروع

  1. بعد تسجيل الدخول، اضغطي على + في الأعلى
  2. اختاري New repository
  3. املئي البيانات:
    • Repository name: data-information-activities
    • Description: أنشطة تفاعلية - البيانات والمعلومات
    • Public: اختاري Public (عام)
    • ✅ ضعي علامة على Add a README file
  4. اضغطي Create repository
📸 ستظهر لك شاشة إنشاء Repository
3
رفع الملفات

الطريقة السهلة (بدون Git):

  1. في صفحة المشروع، اضغطي على Add file
  2. اختاري Upload files
  3. اسحبي جميع ملفات HTML إلى المنطقة المخصصة
    (أو اضغطي "choose your files" واختاري الملفات)
  4. انتظري حتى يكتمل الرفع
  5. اكتبي رسالة في خانة Commit: "إضافة جميع الأنشطة"
  6. اضغطي Commit changes

⚠️ مهم

تأكدي من رفع جميع الملفات دفعة واحدة، بما فيها:
• index.html (الأهم!)
• activity1 حتى activity8
• teacher_dashboard.html
• جميع الملفات الأخرى

4
تفعيل GitHub Pages

الآن سنحوّل المشروع إلى موقع ويب حقيقي!

  1. في صفحة المشروع، اضغطي على Settings (الإعدادات)
  2. من القائمة الجانبية، اضغطي على Pages
  3. في قسم "Source" (المصدر):
    • Branch: اختاري main
    • Folder: اتركيها على / (root)
  4. اضغطي Save
  5. انتظري دقيقة أو دقيقتين...
  6. ستظهر رسالة خضراء بالرابط! 🎉
Your site is published at: https://username.github.io/data-information-activities/

✅ تم بنجاح!

الموقع الآن مباشر على الإنترنت! انسخي الرابط وشاركيه مع الطالبات

5
اختبار الموقع
  1. افتحي الرابط في متصفح جديد
  2. يجب أن ترى الصفحة الرئيسية مع جميع الأنشطة
  3. جرّبي الضغط على أحد الأنشطة للتأكد من عمله
  4. إذا عمل كل شيء - مبروك! 🎉

⚠️ إذا لم يعمل الموقع

• انتظري 5-10 دقائق (أحياناً يأخذ وقت)
• تأكدي أن ملف index.html موجود
• تأكدي أن GitHub Pages مفعّل من Settings → Pages
• جرّبي تحديث الصفحة (Ctrl + F5)

6
مشاركة الرابط

الآن يمكنك مشاركة الرابط بعدة طرق:

  1. WhatsApp: أرسلي الرابط مباشرة للمجموعة
  2. منصة مدرستي: أضيفي الرابط كمصدر تعليمي
  3. QR Code: حوّلي الرابط إلى QR Code (استخدمي qr-code-generator.com)
  4. Google Classroom: أضيفي الرابط كمادة

💡 نصيحة احترافية

اجعلي الرابط أقصر باستخدام خدمة مثل:
• bit.ly
• tinyurl.com
مثال: من username.github.io/data-information-activities
إلى: bit.ly/data-activities

📝 كيفية تحديث الملفات لاحقاً

  1. اذهبي إلى repository في GitHub
  2. اضغطي على الملف الذي تريدين تعديله
