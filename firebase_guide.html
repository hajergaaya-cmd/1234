🔥 دليل Firebase الشامل

تعلمي كيفية ربط الأنشطة التفاعلية بقاعدة بيانات Firebase

1
إنشاء حساب Firebase
  1. اذهبي إلى موقع Firebase: firebase.google.com
  2. اضغطي على Get Started أو Go to Console
  3. سجلي الدخول باستخدام حساب Google الخاص بك
  4. ستُنقلين إلى Firebase Console (لوحة التحكم)

💡 نصيحة

استخدمي حساب Gmail الذي ذكرته ([email protected]) لتسهيل الإدارة

2
إنشاء مشروع جديد
  1. في Firebase Console، اضغطي على Add Project أو إضافة مشروع
  2. أدخلي اسم المشروع، مثال: "أنشطة-البيانات-والمعلومات"
  3. اضغطي Continue
  4. يمكنك تعطيل Google Analytics (غير مطلوب للبداية)
  5. اضغطي Create Project
  6. انتظري حتى يتم إنشاء المشروع (حوالي 30 ثانية)
  7. اضغطي Continue للدخول إلى لوحة التحكم
📸 ستظهر لك شاشة إنشاء المشروع مع حقل لكتابة الاسم
3
تفعيل Firestore Database

Firestore هي قاعدة البيانات التي ستخزن فيها إجابات الطلاب.

  1. من القائمة الجانبية، اضغطي على Firestore Database
  2. اضغطي على Create Database
  3. اختاري Start in test mode (للتجربة)
  4. اختاري الموقع الأقرب لك (مثال: europe-west2 للشرق الأوسط)
  5. اضغطي Enable

⚠️ مهم جداً

Test mode يسمح بالقراءة والكتابة لمدة 30 يوم فقط. بعدها ستحتاجين لتفعيل قواعد الأمان (سأوضح لك كيف لاحقاً)

4
تسجيل تطبيق ويب

الآن نحتاج إلى "مفاتيح الاتصال" بين النشاط وFirebase

  1. في لوحة التحكم الرئيسية، اضغطي على أيقونة </> (Web)
  2. أدخلي اسماً للتطبيق، مثال: "نشاط التفكير الزوجي"
  3. لا تحتاجين لتفعيل Firebase Hosting
  4. اضغطي Register App
  5. مهم: ستظهر لك الآن معلومات Firebase Config - انسخيها!
// ستظهر لك معلومات بهذا الشكل: const firebaseConfig = { apiKey: "AIzaSyXXXXXXXXXXXXXXXXXXXXX", authDomain: "your-project.firebaseapp.com", projectId: "your-project-id", storageBucket: "your-project.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:xxxxx" };

⚠️ احتفظي بهذه المعلومات

ستحتاجينها لاحقاً! انسخيها في ملف نصي أو احتفظي بالصفحة مفتوحة

5
تحديث ملف النشاط

الآن سأعطيك ملف النشاط الجديد المعدّل ليعمل مع Firebase!

ما عليك فعله:

  1. افتحي الملف الجديد الذي سأعطيك إياه
  2. ابحثي عن السطر الذي يقول: // ضعي معلومات Firebase هنا
  3. الصقي معلومات firebaseConfig التي نسختيها في الخطوة 4
  4. احفظي الملف

💡 سهل جداً

سأنشئ لك الملف جاهزاً، كل ما عليك فعله هو نسخ ولصق معلومات Firebase فقط!

6
مشاهدة الإجابات

بعد أن يرسل الطلاب إجاباتهم، يمكنك مشاهدتها بطريقتين:

الطريقة 1: مباشرة في Firebase Console

  1. اذهبي إلى Firebase Console
  2. اضغطي على Firestore Database
  3. اختاري Data
  4. ستجدين مجلد اسمه pair-answers
  5. كل إجابة ستكون وثيقة منفصلة بداخلها

الطريقة 2: لوحة التحكم المخصصة (الأفضل)

سأنشئ لك لوحة تحكم مخصصة متصلة بFirebase مباشرة، تعرض جميع الإجابات بشكل جميل ومنظم!

7
تأمين قاعدة البيانات (مهم!)

بعد 30 يوم من Test Mode، ستحتاجين لتحديث قواعد الأمان:

  1. في Firestore Database، اضغطي على تبويب Rules
  2. استبدلي القواعد الموجودة بالقواعد التالية:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // السماح بالكتابة للجميع (للطلاب) match /pair-answers/{document=**} { allow read, write: if true; } } }

⚠️ للاستخدام التعليمي فقط

هذه القواعد تسمح للجميع بالقراءة والكتابة. للاستخدام الفعلي، يُفضل إضافة مصادقة أو قيود إضافية
